# Changelog

Follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [SemVer](https://semver.org/).

## [0.2.0] - unreleased

Breaking: the whole public API is English. There are no deprecated aliases; move to the new names. Published types are generated by `tsc`, and their relative specifiers end in `.js`.

- Types and data: `Palavra` -> `Word`, `Tema` -> `Theme`, `TEMA_PADRAO` -> `DEFAULT_THEME`, `EpData` -> `EpisodeData` (`voz` -> `voice`, `palavras` -> `words`, `cenas` -> `scenes`, `fechamento` -> `outro`, `fundoLinhas` -> `backgroundLines`, `legendaPx` -> `captionPx`, `golpes` -> `hits`), `EpCena` -> `EpisodeScene` (`rotulo` -> `label`, `sons` -> `sounds`), `Som` -> `Sound` (`f` -> `sound`), `Golpe` -> `Hit` (`tipo` -> `type`, `tudo` -> `all`), `Grupo` -> `Group`, `LongoData` -> `LongData`, `CenaLongo` -> `LongScene`, `FechoLongo` -> `LongEndcard`.
- Functions and components: `Episodio` -> `Episode`, `Longo` -> `Long`, `Rotulo` -> `Label`, `Fundo` -> `Background`, `agrupar` -> `groupWords`, `TemaProvider` -> `ThemeProvider` (prop `tema` -> `theme`), `useTema` -> `useTheme`, `temaDaMarca` -> `themeFromBrand`, `surge` -> `appear`, `mkAt` -> `makeAt`, `mkAtG` -> `makeAtGlobal`, `janela` -> `fadeWindow`.
- Theme fields: `fundo` -> `background`, `fundoCapa` -> `coverBackground`, `destaque` -> `accent`, `texto` -> `text`, `suave` -> `muted`, `erro` -> `error`, `caixa` -> `box`, `caixaLongo` -> `longBox`, `codigo` -> `code`, `fonte` -> `font`. New `mascotPath` (default `mascots/{name}.png`). `themeFromBrand` reads the English `brand.json` shape (`colors`, `fonts.title`, `fonts.mono`).
- Error messages are English (`phrase not found: ...`).

## [0.1.0] - 2026-11-07

First published version, extracted from the project where it was born. Publishes compiled `dist/` (ESM + `.d.ts`); `react` and `remotion` are peers.
