# @praeko/studio-core

Motor do Praeko Studio (peças Remotion): episódio por voz e palavras com tempo, legendas palavra a palavra, golpes de edição, fechamento e tema da marca. Biblioteca para projetos criados com [`@praeko/studio`](https://www.npmjs.com/package/@praeko/studio) (`praeko studio init` já instala e configura).

## Instalar
```sh
# npm
npm install @praeko/studio-core remotion react
# yarn
yarn add @praeko/studio-core remotion react
# pnpm
pnpm add @praeko/studio-core remotion react
# bun
bun add @praeko/studio-core remotion react
```
Peers: `remotion` ^4.0.539 (todos os pacotes `@remotion/*` na mesma versão) e `react` ^19. Node 22 ou mais novo. Uso: `praeko studio docs episodio-yaml`.
