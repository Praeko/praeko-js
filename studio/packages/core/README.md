# @praeko/studio-core

The Praeko Studio engine (Remotion parts): voice-driven episodes with timed words, word-by-word captions, editing hits, outro and brand theme. A library for projects created with [`@praeko/studio`](https://www.npmjs.com/package/@praeko/studio) (`praeko studio init` installs and configures it).

Details in [LICENSES.md](./LICENSES.md).

## Install
```sh
# npm
npm install @praeko/studio-core remotion react
# yarn
yarn add @praeko/studio-core remotion react
# pnpm
pnpm add @praeko/studio-core remotion react
# bun
bun add @praeko/studio-core remotion react
```
Peers: `remotion` ^4.0.539 (all `@remotion/*` packages on the same version) and `react` ^19. Node 22 or newer. Usage: `praeko studio docs episode-yaml`.
