# Changelog

Follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [SemVer](https://semver.org/).

## [Unreleased]

## [0.4.2] - 2026-11-25

### Changed
- `SlabStage` over your own video (`base`): the stage is drawn over the video on a transparent canvas, with only the slab (the scene's panel), the props and their soft shadow on an invisible floor; floor, back wall, grid, sun and fog are left out. It is marked `overBase`, so the Episode of `@praeko/studio-core` (this release) puts the video under it; with an older core the flat scenes are used over the video, as before. Without `base` nothing changes.

### Added
- `stageLayers(stage, overVideo)`: what the 3D stage draws around the slab, as data (pure, tested without a GPU).

## [0.4.1] - 2026-11-24

### Fixed
- The `box` item honours `pos` in the free layout (it used to stack at the top of the frame, full width, like an item without a position).

## [0.4.0] - 2026-11-24

Additive: without `style`/`base` the parts render exactly as in 0.3.0.

### Changed
- Peer dependency: `@praeko/studio-core` `^0.4.0` (was `^0.3.0`); the parts read the skins and `base` that only core 0.4.0 has. `react` and `remotion` peers are unchanged.

### Added
- Every declarative item (`text`, `big`, `box`, `line`, `bubble`, `code`, `card`, `bar`, `bars`, `stack`, `row`) and `Panel` read the skin tokens; the fixed bar color `#b9453a` became a token.
- `EpisodeDecl` picks the skin from `spec.style` (written by `praeko studio compile`), or a `skin` prop; `id` overrides the composition id. `skinAndTheme` exposes the rule.
- `HandBorder` (chalk outline that draws itself, deterministic) and the comic speech balloon (`bubble.kind: comic`).
- `SlabStage`: the 3D stage of the 3D skins (path A': the panel DOM rasterized into a texture on a lit slab; floor, props, studio light, one camera shot per scene; fonts embedded). `three` is a dependency loaded with a dynamic import, only by 3D skins.
- `base` video and optional `outro` in `EpisodeSpec`; `sceneWindows`: with `base` nothing unmounts between scenes (no 0.1 s gap), only the panel enters and leaves.
- Text that does not fit: `box`, `line`, `big`, `code` and a centered `row` shrink until they fit their width (`useFitText`, `useFitRow`, `FIT_MIN` 45%, at most 4 steps). Measured from the layout before the frame is drawn and only ever shrinking, so it is deterministic; an item that already fits is untouched.
- 3D stage: `window`/`phone` videos (and any image) show on the slab: the panel's images are waited for and inlined before rasterizing; the face is re-rasterized after every commit, so self-adjusting parts are drawn in their final state; `stage.faceLight`.

### Fixed
- `text` in a `layout: free` scene without `font` fell back to the browser's serif font; free scenes now inherit the theme font. Only frames that show such text change (PNG-still comparison against 0.3.0).
- Comic speech balloon (`bubble`): the tail no longer leaves a seam where it meets the balloon outline.
- Chalk outline (`HandBorder`): the stroke stays inside the box (it used to spill out), and text fitting stops after 4 steps (it could shrink without end, React error #185 in the `chalkboard` gallery).

## [0.2.3], [0.2.2], [0.2.1] - 2026-11-08

## [0.2.0] - 2026-11-07

Breaking: the whole public API is English, and the declarative components read the English `episode.spec.json` only. There are no deprecated aliases; regenerate the spec with `praeko studio compile` (or run `praeko studio migrate`). Published types are generated by `tsc`, and their relative specifiers end in `.js`.

- Parts: `PainelD` -> `Panel` (`titulo` -> `title`), `Caixa` -> `Box` (`cor` -> `color`), `Linha` -> `Line`, `Big` (`cor` -> `color`), `Balao` -> `Bubble` (`autor` -> `author`), `Codigo` -> `Code` (`titulo` -> `title`, `linhas` -> `lines`, `cor` -> `color`, `marca` -> `mark`), `Janela` -> `Window` (`duracao` -> `clipDuration`, `de` -> `from`), `Celular` -> `Phone`, `Gato` -> `Mascot` (`nome` -> `name`, `tam` -> `size`; the image path comes from the theme `mascotPath`), `Moldura` -> `Frame` (`titulo` -> `title`, `cor` -> `color`, `tam` -> `size`).
- Declarative: `EpisodioDecl` -> `EpisodeDecl` (props `spec`, `words`, `theme`, `components`; were `spec`, `palavras`, `tema`, `pecas`), `EpSpec` -> `EpisodeSpec`, `CenaSpec` -> `SceneSpec`, `epDataDeSpec` -> `episodeDataFromSpec`, `LongoDecl` -> `LongDecl`, `LongoSpec` -> `LongSpec`, `CenaLSpec` -> `LongSceneSpec`, `longoDeSpec` -> `longDataFromSpec`, `CapaLongoSpec` -> `LongCoverSpec`, `CapasLongo` -> `LongCovers`, `CapaLongo16x9` -> `LongCover16x9`, `CapaLongoVertical` -> `LongCoverVertical`.
- Long parts: `CodigoL` -> `CodeL`, `CartaoL` -> `CardL`, `TxtL` -> `TextL`, `surgeL` -> `appearL`, `LinhaCodigo` -> `CodeLine`; props `titulo` -> `title`, `cor` -> `color`.
- Spec shape: see `docs/studio-ingles.md` (4.3, 4.4, 4.7) in the repository; new `resolveColor` helper.
- Defaults: the `Mascot` card no longer defaults to a game-specific path, and the `Bubble` default author is `— someone, in the chat`. Peer dependency: `@praeko/studio-core` ^0.2.0.

## [0.1.0] - 2026-11-07

First published version, extracted from the project where it was born. Publishes compiled `dist/` (ESM + `.d.ts`); `react` and `remotion` are peers.
