# Changelog

Follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [SemVer](https://semver.org/).

## [0.2.0] - unreleased

Breaking: the whole public API is English, and the declarative components read the English `episode.spec.json` only. There are no deprecated aliases; regenerate the spec with `praeko studio compile` (or run `praeko studio migrate`). Published types are generated by `tsc`, and their relative specifiers end in `.js`.

- Parts: `PainelD` -> `Panel` (`titulo` -> `title`), `Caixa` -> `Box` (`cor` -> `color`), `Linha` -> `Line`, `Big` (`cor` -> `color`), `Balao` -> `Bubble` (`autor` -> `author`), `Codigo` -> `Code` (`titulo` -> `title`, `linhas` -> `lines`, `cor` -> `color`, `marca` -> `mark`), `Janela` -> `Window` (`duracao` -> `clipDuration`, `de` -> `from`), `Celular` -> `Phone`, `Gato` -> `Mascot` (`nome` -> `name`, `tam` -> `size`; the image path comes from the theme `mascotPath`), `Moldura` -> `Frame` (`titulo` -> `title`, `cor` -> `color`, `tam` -> `size`).
- Declarative: `EpisodioDecl` -> `EpisodeDecl` (props `spec`, `words`, `theme`, `components`; were `spec`, `palavras`, `tema`, `pecas`), `EpSpec` -> `EpisodeSpec`, `CenaSpec` -> `SceneSpec`, `epDataDeSpec` -> `episodeDataFromSpec`, `LongoDecl` -> `LongDecl`, `LongoSpec` -> `LongSpec`, `CenaLSpec` -> `LongSceneSpec`, `longoDeSpec` -> `longDataFromSpec`, `CapaLongoSpec` -> `LongCoverSpec`, `CapasLongo` -> `LongCovers`, `CapaLongo16x9` -> `LongCover16x9`, `CapaLongoVertical` -> `LongCoverVertical`.
- Long parts: `CodigoL` -> `CodeL`, `CartaoL` -> `CardL`, `TxtL` -> `TextL`, `surgeL` -> `appearL`, `LinhaCodigo` -> `CodeLine`; props `titulo` -> `title`, `cor` -> `color`.
- Spec shape: see `docs/studio-ingles.md` (4.3, 4.4, 4.7) in the repository; new `resolveColor` helper.
- Defaults: the `Mascot` card no longer defaults to a game-specific path, and the `Bubble` default author is `— someone, in the chat`. Peer dependency: `@praeko/studio-core` ^0.2.0.

## [0.1.0] - 2026-11-07

First published version, extracted from the project where it was born. Publishes compiled `dist/` (ESM + `.d.ts`); `react` and `remotion` are peers.
