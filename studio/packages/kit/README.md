# @praeko/studio-kit

Praeko Studio scene parts (panel, box, line, bubble, code, window, phone, frame) and the declarative episode built from the compiled `episode.yaml`. A library for projects created with [`@praeko/studio`](https://www.npmjs.com/package/@praeko/studio) (`praeko studio init` installs and configures it).

## Install
```sh
# npm
npm install @praeko/studio-kit remotion react
# yarn
yarn add @praeko/studio-kit remotion react
# pnpm
pnpm add @praeko/studio-kit remotion react
# bun
bun add @praeko/studio-kit remotion react
```
Peers: `remotion` ^4.0.539 (all `@remotion/*` packages on the same version) and `react` ^19. Node 22 or newer. Usage: `praeko studio docs episode-yaml`.
